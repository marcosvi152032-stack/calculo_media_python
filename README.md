# Sistema de Controle de Estoque

## Título e Descrição
Um sistema simples em Python para gerenciamento de estoque via terminal. Permite adicionar, atualizar, remover e visualizar produtos e suas quantidades utilizando dicionário.

## Linguagens Utilizadas
*Python 3.14*

## Como Instalar e Executar
*Executar através de uma IDE ou compiladores online (mycompiler) com python instalado*
